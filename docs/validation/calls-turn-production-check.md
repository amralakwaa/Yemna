# تحقق إنتاجي من إعداد TURN والمكالمات

تمت مراجعة صفحة `/messages` المنشورة بعد إصدار إصلاح تطبيع إعداد TURN. استعادت الجلسة حسابها، وعُرضت قائمة المحادثات الحية بصورة طبيعية دون تنبيه عام أو كشف بيانات اعتماد TURN.

لم يُجر اختبار مكالمة فعلية بين حسابين في هذا التحقق، لتجنب بدء اتصال أو تشغيل كاميرا وميكروفون دون طلب صريح. تظل تجربة مكالمة بين حسابين وعلى شبكتين مختلفتين خطوة التحقق الميدانية التالية.
