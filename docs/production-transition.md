# حزمة الانتقال الإنتاجي — يمنا

## نطاق الحزمة

تصف هذه الوثيقة المخرج المطلوب للانتقال المنضبط من نسخة التطوير إلى تشغيل إنتاجي. طبقة الخادم تعمل كمونوليث منظم في NestJS، تتصل بـ PostgreSQL بواسطة Prisma، وتبقى الواجهة React/Vite مستقلة عن أسرار البيئة. جميع قيم الاتصال والأسرار تُدار في Secrets ولا تدخل Git أو ملفات الواجهة.

| مجال الجاهزية | الوضع الحالي | شرط الإغلاق للإنتاج |
|---|---|---|
| قاعدة البيانات | PostgreSQL متصل والترحيلات `0001`–`0005` مطبقة | نسخة احتياطية مؤكدة وخطة ترحيل مدروسة لكل تغيير لاحق |
| المصادقة وRBAC | JWT، refresh token، وحماية الإدارة مختبرة | مراجعة أسرار الإنتاج وتهيئة CORS للنطاق الفعلي |
| اختبارات التطبيق | 43 اختباراً للخدمات والحراسة وHTTP عند آخر تحقق | تشغيل `pnpm test` و`pnpm check` و`pnpm build` ضمن خط CI قبل كل نشر |
| التخزين الإعلامي | وحدة Media تستخدم طبقة التخزين الخادمية | سياسة احتفاظ، حدود رفع، وفحص نوع الملفات في الإنتاج |
| الواجهة | التدفقات الأساسية موصولة جزئياً | ربط المنشورات والتفاعلات والرسائل والمجتمعات تدريجياً قبل إزالة كل بيانات العرض التجريبية |
| التشغيل اللحظي | غير مفعّل | Redis وWebSocket ونمط استضافة مستمر قبل تفعيل البث والاتصالات الحية |

## خطوات التشغيل الآمن

ابدأ بتعيين الأسرار من لوحة الإدارة فقط، ثم طبّق ترحيلات Prisma على قاعدة النسخة المستهدفة. شغّل مجموعة الاختبارات والتحقق والبناء قبل الحفظ والنشر. افحص `GET /api/health` بعد الإقلاع؛ ينبغي أن يعيد حالة الخدمة وحالة قاعدة البيانات دون كشف عنوانها أو كلمة مرورها. افحص أيضاً رفض مسار الإدارة دون رمز، ثم اختبر التدفقات المصرح بها بحساب مخصص غير مميز قبل منح دور المدير.

## حدود الإصدار الحالي

لا تتضمن الحزمة الحالية Redis أو طابور مهام أو WebSocket أو بثاً حياً حقيقياً. هذا قرار مقصود وليس نقصاً مخفياً: هذه المتطلبات تحتاج بنية دائمة واتصالاً طويل الأمد، وهي غير مناسبة لتفعيل تجريبي على تشغيل خامل. كما أن بعض شاشات الواجهة ما زالت تقدم بيانات عرض إلى أن يُنجز الربط التدريجي المدون في مصفوفة تدقيق المسارات.

## قرار الإطلاق

الإصدار صالح لتقييم التكامل الخلفي وتدفقات المصادقة والتغذية والملفات الشخصية في بيئة محمية. لا ينبغي اعتباره إطلاقاً عاماً كاملاً قبل إتمام ربط الصفحات ذات الأولوية، وإعداد التشغيل اللحظي للميزات التي تتطلبه، وتنفيذ مراجعة أمنية تشغيلية للأسرار وCORS والنسخ الاحتياطي.
