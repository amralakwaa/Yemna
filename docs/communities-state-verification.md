# تحقق حالات صفحة المجتمعات

تُدار صفحة `/communities` في `client/src/pages/YemnaPages.tsx` عبر استعلام React Query ذي المفتاح `['rest', 'communities']` ودالة `api.getCommunities`. الجدول التالي يربط كل حالة عرض بالشرط البرمجي الفعلي، كي لا يكون الربط بالـ REST مجرد استبدال شكلي للبيانات.

| الحالة | الشرط البرمجي | نتيجة العرض |
|---|---|---|
| التحميل | `communitiesQuery.isLoading` | مؤشر دوران ونص «يجري تحميل المجتمعات…». |
| الخطأ | `communitiesQuery.isError` | كتلة خطأ صريحة بعنوان «تعذر تحميل المجتمعات». |
| الفراغ | `communitiesQuery.data?.length === 0` | كتلة فارغة بعنوان «لا توجد مجتمعات بعد». |
| النجاح | القائمة غير فارغة | بطاقات مبنية من `communitiesQuery.data` مع اسم المجتمع وعدد الأعضاء وحالة الانضمام. |
| الدخول | `requestJoin` يتحقق من `hasRestSession()` قبل `api.joinCommunity` | يمنع الانضمام غير المصرح ويعرض رسالة «سجّل الدخول أولاً للانضمام إلى مجتمع». |

تم التحقق بصرياً من المسار على هاتف بعرض 375 بكسل بعد إصلاح تباين زر الإنشاء، كما اجتازت الشفرة اختبارات المشروع والتحقق من الأنواع والبناء الإنتاجي.
