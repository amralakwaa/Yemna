# دليل التشغيل والتحقق — Backend يمنا

يوضح هذا الدليل حالة طبقة الخادم الحالية وكيفية تشغيلها والتحقق منها دون نسخ أي أسرار إلى المشروع. يستخدم الخادم **NestJS** مع **Prisma** وPostgreSQL تحت البادئة `/api`، بينما تبقى واجهة Vite متاحة للمسارات المرئية للتطبيق.

| المجال | الحالة الحالية | نقطة الوصول أو الضمان |
|---|---|---|
| الفحص الصحي | متاح | `GET /api/health` ويعرض حالة الخدمة والقاعدة دون قيم اتصال |
| REST الإصدار الأول | متاح | `/api/v1/*` للمصادقة والمستخدمين والمحتوى والعلاقات والمجتمعات والرسائل والإشعارات والوسائط والبحث والدعم والإدارة |
| المصادقة | متاح | Bearer access token قصير العمر وrefresh token في Cookie آمنة من JavaScript |
| الصلاحيات | متاح | الإدارة محمية بدور `ADMIN` عبر `JwtAuthGuard` و`RolesGuard` |
| قاعدة البيانات | متصلة | PostgreSQL عبر `YEMNA_DATABASE_URL` من Secrets فقط |
| الواجهة الموصولة | متاح جزئياً | التسجيل والدخول والتغذية والملف الشخصي تستخدم REST الحقيقي؛ بقية الصفحات تحافظ مؤقتاً على واجهاتها التجريبية |

## التحقق المنفذ

تغطي مجموعة الاختبارات الحالية خدمات المجالات، والمصادقة، والأدوار، والاتصال بقاعدة البيانات، واختبار HTTP متكاملاً. يثبت اختبار HTTP أن الطلب غير الحامل لـ Bearer token يُرفض لمسار محمي، وأن المستخدم العادي يُمنع من الإدارة، وأن رمز المدير الموقّع صالح للوصول إلى إحصاءات الإدارة.

| الأمر | الهدف |
|---|---|
| `pnpm test` | تشغيل اختبارات Vitest للخدمات والمصادقة وRBAC والاختبار التكاملـي HTTP |
| `pnpm check` | تحقق TypeScript دون إنشاء مخرجات |
| `pnpm build` | توليد Prisma Client وبناء الواجهة والخادم للإنتاج |
| `pnpm prisma migrate deploy` | تطبيق ترحيلات Prisma على قاعدة مهيأة فعلياً، عند الحاجة فقط |

## متغيرات البيئة

تُقرأ جميع القيم الحساسة من منصة Secrets. لا ينبغي إنشاء ملفات أسرار قابلة للالتزام أو طباعة قيم المتغيرات في طرفية التطوير. أهم المفاتيح هي `YEMNA_DATABASE_URL` و`YEMNA_JWT_ACCESS_SECRET` و`YEMNA_CORS_ORIGINS`. يظل `.env.example` قالباً تعليمياً بقيم غير حقيقية فقط.

## القيود والخطوات اللاحقة

الميزات اللحظية، بما فيها WebSocket والمهام المؤجلة وRedis، لم تُفعّل بعد؛ إذ تتطلب خدمة Redis وتشغيلاً مستمراً يناسب الاتصالات الطويلة. كما أن بقية صفحات الواجهة لا تزال تحتاج ربطاً متدرجاً بالـ REST API قبل إزالة كل بيانات العرض التجريبية. لا يمنع ذلك تشغيل تدفقات المصادقة والتغذية والملفات الشخصية الموصولة حالياً.
