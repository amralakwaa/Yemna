# يمنا | Yemna

**منصة التواصل والمجتمع الرقمي اليمني:** منصة تواصل اجتماعي كاملة فيها ملفات شخصية ومنشورات ومجتمعات ورسائل فورية وقصص (Stories) ووسائط وإشعارات، مع لوحة إدارة ومساعد ذكي.

</div>

---

## ماذا يحتوي المشروع؟ | What's inside

<div dir="rtl">

### للمستخدم
- **حساب وملف شخصي:** تسجيل دخول واستعادة الجلسة، وتعديل الملف الشخصي، ومجموعات خاصة في الملف.
- **العلاقات:** متابعة وصداقات، واقتراحات أصدقاء يمكن إخفاؤها، وإعدادات خصوصية للعلاقات، وحظر.
- **المحتوى:** منشورات، وقصص مع عدّاد مشاهدات، وألبومات وسائط، ومقاطع قصيرة (Reels) بتصنيفات، وصفحة استكشاف وبحث.
- **المجتمعات:** إنشاء مجتمع وصفحة تفاصيل له.
- **الرسائل:** صندوق رسائل ومحادثات مباشرة فورية مع إرسال الوسائط.
- إشعارات، ومساعد ذكي، وصفحة دعم وبلاغات.

### للإدارة
- لوحة إدارة محمية بصلاحيات، فيها أدوات ذكاء اصطناعي.

### البنية التقنية
- **واجهة** React 19 مع Vite وwouter، و**خادم** Node.js بـ Express وtRPC، مع وحدات NestJS.
- **قاعدة بيانات MySQL** بعشر ترحيلات Prisma مرتّبة حسب المراحل: المصادقة، ثم المحتوى، ثم المجتمعات والرسائل والإشعارات، ثم الألبومات، ثم الدعم، ثم القصص ومشاهداتها، ثم وسائط الرسائل، ثم الخصوصية، ثم اقتراحات الأصدقاء.
- اتصال فوري عبر Socket.IO، وRedis (ioredis)، وتخزين ملفات على S3.
- التحقق من المدخلات بـ Zod، واختبارات Vitest، منها اختبارات عقود (contract tests) للجلسة والبيانات وتخطيط الجوال.

</div>

## التقنيات | Tech stack

| | |
| --- | --- |
| Frontend | React 19, TypeScript, Vite, wouter, Tailwind CSS 4, Framer Motion |
| Backend | Node.js, Express, tRPC, NestJS 11, Socket.IO |
| Data | MySQL, Prisma 6, Drizzle ORM, Redis |
| Storage | AWS S3 |
| Testing | Vitest |

## التشغيل محلياً | Local setup

```bash
git clone https://github.com/amralakwaa/Yemna.git
cd Yemna
npm install
# أنشئ ملف .env فيه DATABASE_URL وبيانات Redis و S3
npm run prisma:generate
npm run prisma:migrate
npm run dev
```

لتشغيل الاختبارات:

```bash
npm test
```
